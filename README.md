🍣 Luxury Restaurant Landing Page

A modern and responsive luxury restaurant landing page built from scratch using HTML5 and CSS3.

This project focuses on creating a premium restaurant experience through elegant layouts, food-focused sections, responsive design, typography, spacing, hover effects, and a structured reservation interface.

🌐 Live Demo

👉 "View Live Website" (https://ahmadraza-cyber.github.io/Luxury-Restaurant-Landing-Page/)

✨ Features

- 🍣 Luxury restaurant-inspired UI
- 🖼️ Full-width hero section
- 📖 Restaurant story / About section
- 📍 Location and opening-hours section
- 🍽️ Menu and popular dishes sections
- 🎉 Dining and private event sections
- 💬 Customer testimonials
- 📅 Upcoming events section
- 📋 Table reservation form
- 📧 Newsletter subscription section
- 🖱️ Hover effects and smooth visual interactions
- 📱 Responsive layout for different screen sizes
- 🌙 Elegant dark luxury-style visual design

🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Transitions
- CSS Variables
- Responsive Design
- SVG / Image Assets

📚 What I Practiced

While building this project, I practiced:

- Structuring a complete multi-section landing page with semantic HTML
- Building layouts using Flexbox and CSS Grid
- Creating responsive designs with Media Queries
- Working with typography, spacing, and visual hierarchy
- Creating restaurant menu and content cards
- Designing reservation and newsletter forms
- Adding hover effects and CSS transitions
- Working with background images and layered sections
- Managing reusable CSS variables
- Creating a consistent luxury-style visual design
- Deploying a frontend project using GitHub Pages

📱 Responsive Design

The landing page is designed to adapt to different screen sizes, including:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

🚀 Deployment

This project is deployed using GitHub Pages.

The project uses a dark, elegant visual direction combined with large food imagery, refined typography, spacious layouts, and warm accent elements to create a premium restaurant atmosphere.
